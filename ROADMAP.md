# 🗺️ CyberRakshak AI — Roadmap

This roadmap outlines the planned development milestones for CyberRakshak AI.

## Phase 1 — Foundation (Current)

- [x] Project scaffolding (docs, Docker, CI/CD)
- [x] Backend: FastAPI application with health endpoint
- [x] Frontend: React + Vite application
- [x] GitHub repository setup & CI pipeline

## Phase 2 — Core Detection Engine

- [ ] Network traffic capture & normalization module
- [ ] Anomaly detection with Isolation Forest / LOF
- [ ] Signature-based detection rules engine
- [ ] Threat scoring & prioritization system
- [ ] PostgreSQL persistence layer

## Phase 3 — ML / AI Intelligence

- [ ] Supervised classifier (malicious vs. benign) with scikit-learn
- [ ] Feature engineering pipeline
- [ ] Model training pipeline & versioning (MLflow)
- [ ] Real-time inference endpoint
- [ ] Drift detection & model retraining

## Phase 4 — Response & Automation

- [ ] Automated mitigation playbooks
- [ ] Alerting (email, Slack, webhook)
- [ ] Audit logging & case management
- [ ] RBAC & multi-tenant support

## Phase 5 — Dashboard & UX

- [ ] Real-time threat dashboard (websockets)
- [ ] Attack timeline & trend analytics
- [ ] Incident drill-down views
- [ ] Dark mode & responsive design polish

## Phase 6 — Hardening & Scale

- [ ] Redis caching & queueing
- [ ] Horizontal scaling (Kubernetes manifests)
- [ ] Penetration testing & security audit
- [ ] Full test coverage & load testing

## Milestones

| Milestone | Target | Description |
|-----------|--------|-------------|
| M1 | Phase 2 complete | Functional threat detection MVP |
| M2 | Phase 4 complete | Automated response capability |
| M3 | Phase 6 complete | Production-ready platform |
